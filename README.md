# Software Development Processes Powered by AI Agents

A hands-on course where you build a suite of AI agents that automate the core phases of modern software development — from architecture and requirements through CI/CD, testing, and team delivery.

Each module produces a working agent (or multi-agent system) that solves a real engineering workflow problem. By the end of the course you will have a full toolkit of agents capable of handling Git workflows, architecture documentation, requirements engineering, deployment pipelines, and test-driven development — all working together in a final team project.
